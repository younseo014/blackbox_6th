# 로컬 영상 맥락 모델 도입 — 2026-11-10

## 적용 범위

사용자가 외부 모델 도입을 허용한 뒤 로컬 CLIP ViT-B/32 ONNX int8 모델을 연결했다.
이는 이미지와 업무 문장을 비교하는 모델이며, 카페 5종에 특화한 행동·경계 모델이 아니다.
현재 카페 정확도나 의미 있는 업무 1회의 경계가 개선됐다는 실측 주장은 하지 않는다.

- 원본 모델: https://github.com/openai/CLIP
- ONNX 변환 배포: https://huggingface.co/Xenova/clip-vit-base-patch32
- 라이선스: 양쪽 모두 MIT. OpenAI 저작권 문구를 앱 정적 파일에 포함.
- 고정 revision: `6b7c523703ae26e39be4b03774966f8571c7f523`.
- 모델: 89,117,001 bytes, SHA-256 `583fd1110a514667812fee7d684952aaf82a99b959760c8d7dca7e0ab9839299`.
- 준비: `npm run prepare:actions`. 실행 시 모델 다운로드·서버·API 키·Python이 필요하지 않음.
- 문장 수정 시: 같은 revision의 tokenizer/text ONNX를 준비한 개발 환경에서 `scripts/build-local-action-model.py` 실행. 참가자 자료는 사용하지 않음.

## 실제 동작

1. 카메라 연결 시 모델을 준비한다. 자체테스트 미리보기에서는 영상 후보/좌표 표본을 수집하지 않는다.
2. 촬영 시작 뒤 약 1초 간격으로 카메라 1의 화면을 별도 Worker에서 분석한다. 이전 추론이 진행 중이면 추가 요청을 쌓지 않는다.
3. 카페 5종, 전화 사용, 고객 응대, 이동, 원인 미확인 정지/휴식, 설정/기타, 사람 없는 화면을 대안으로 함께 비교한다.
4. 문장 cosine 0.28 이상·대안과 차이 0.04 이상이 2초 이상 3회 이어지고 몸도 관측돼야 구간 후보로 사용한다. 이 값은 아직 카페 정답 자료로 보정되지 않은 운영 기준이다.
5. 카페 업무 후보에는 실제 스켈레톤 움직임도 필요하다. 정적인 컵/싱크대 화면만으로 업무를 만들지 않는다. 영상 후보 경계와 관측 움직임의 겹치는 범위를 사용한다.
6. 동일 업무 전후에 전화/응대/원인 미확인 정지 후보가 끼면 30초 이내에서 하나의 후보 업무로 묶되 중간 시간의 원인 표시는 보존한다. 다른 업무·이동을 가로질러 자동 병합하지 않는다.
7. 개인 동작과 강하게 충돌하거나 좌표 누락·중단이 포함된 결과는 검토함으로 보낸다. 충분한 학습 모드 후보는 `labelSource: visual_model`로 개인 표본에 추가하고 분석 모드 결과는 추가하지 않는다. 수동 확정 표본과 구분되며 모두 정정·철회 가능하다.
8. 원본 영상·음성·이미지 벡터는 저장/전송하지 않는다. capture manifest에는 후보 이름·종류·시각·cosine·후보 차이·몸 관측 여부만 기록한다. CSV에는 모델 출처·유사도·연속 표본 수·라벨 출처를 추가했다.

## 중단·정지 처리

- 영상의 전화/고객 응대는 **원인 후보**이며 실제 통화나 응대의 확정이 아니다.
- 원인 미확인 정지/휴식 후보를 외부 방해로 확정하지 않는다. 포즈로 관측된 정지는 기존 행동 변화 신호로 유지한다.
- 중단 의심·좌표 누락과 겹친 시간은 행동 변화 집계에서 보류한다. 원본 수행시간과 정지시간은 삭제하지 않는다.

## 검증과 남은 한계

- 실제 가중치로 로컬 Chrome Worker 추론 성공: 시험 화면 1회 약 216ms, 모델 생성 포함 약 808ms. 해당 기기·시험 입력의 측정이며 Windows/3캠/실시간 처리 보장이 아니다.
- Electron의 `memoryguard://` 프로토콜에서 실제 모델 실행 후 4개 후보 메타데이터 저장 확인. 서버와 원본 이미지 저장 없음.
- 고립된 프레임, 미관측 몸, 후보 차이 부족, 관측 공백, 정적 장면, 전화 끼임, 중복 시간 집계에 대한 단위 테스트 추가.
- **학습된 행동 완료 경계 모델은 아니다.** 같은 장면/같은 업무가 연속되면 수행 횟수를 병합할 수 있고 짧은 동작은 보류할 수 있다. 카메라 1에서 도구가 안 보이면 불확실해질 수 있다.
- 자동 학습 표본은 모델의 가설이며 정답이 아니다. 오류가 개인 표본으로 전파될 가능성이 남아 있다. 정답 라벨과 경계가 있는 독립된 개발용 촬영으로 운영 기준과 자동 학습 정책을 보정해야 한다.
- 기존 2차 첨부 자료는 스켈레톤·메타데이터이고 이 모델에 필요한 원본 이미지가 없다. 당시 18–32초 혼합 구간이 개선됐다고 소급 주장할 수 없다.
- 의료·임상 성능과 장시간 실제 카페 성능은 검증하지 못했다.
