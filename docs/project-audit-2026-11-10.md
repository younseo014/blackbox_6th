# Memory Guard 요구사항 및 수정 감사 — 2026-11-10

## 범위와 지시 우선순위

현재 대화와 같은 작업 폴더의 프로젝트 대화를 조회했다. 최신 사용자 지시가 이전 구현·문서보다 우선한다. 기존 사용자 변경은 보존한다. 외부 모델 도입은 처음에는 보류했으나, 이후 사용자가 로컬 실행·라이선스 확인 후 적용을 명시적으로 허용했다. 과학적·임상적 성능을 합성 테스트 통과와 혼동하지 않는다.

## 미해결 — 심각도 순

1. **P0 / 자동 업무 학습·분류 성능 미검증**: 승인 후 MIT CLIP 로컬 영상 맥락 모델을 연결했다. 연속 맥락·관측 움직임이 충분한 경우 수동 확정 없이 라벨과 개인 학습 표본을 만들고, 불확실·충돌·관측 누락은 검토로 보낸다. 다만 CLIP은 카페 특화 행동 모델이 아니고 운영 기준과 자동 학습의 라벨 오류율은 독립된 카페 자료로 검증하지 못했다. 자동 표본의 오류 전파 가능성이 남는다.
2. **P0 / 의미 있는 업무 1회 경계**: 새 촬영에서는 연속 영상 맥락과 포즈 움직임을 결합해 경계를 구성한다. 같은 업무의 반복 완료 횟수는 구분하지 못할 수 있다. 스켈레톤만 있는 과거 2차 자료는 새 영상 모델을 소급 적용할 수 없어 당시 18–32초 혼합 문제가 해결됐다고 주장할 수 없다. 촬영 중 최근 맥락 후보는 표시하지만 최종 구간/CSV는 종료 후 생성한다.
3. **P0 / 노이즈 원인 확정 불가**: 새 모델의 전화/고객 응대 후보를 별도 기록한다. 실제 통화·응대의 확정이 아니며 정답 자료로 검증되지 않았다. 원인 미확인 정지/휴식은 외부 방해로 단정하지 않고 기존 정지 신호를 유지한다. 마이크·외부 API를 사용하지 않는다.
4. **P1 / 4주·약 15GB·장시간 동작**: 좌표 압축은 있지만 목표 기간 실측이 없다. 종료 분석·전체 ZIP 내보내기는 전체 세션/JSON을 메모리에 적재한다. 구간 조회 개선·ZIP 손상 방지는 했으나 스트리밍/ZIP64 및 장시간 누적 분석은 아직 없다. 목표 PC와 실제 장시간 촬영 자료로 메모리·디스크 예산 확인이 필요하다.
5. **P1 / 3캠 실제 환경·좌표 보정**: 동시 관측과 정규화 영상 좌표로 동작하며, 보정된 3D 복원이 아니다. 각도/가림/조명·실제 카메라 3대로 검증하지 못했다. 고정 화면 비율을 가정하는 일부 특징도 남아 있다.
6. **P1 / 추적 성능 기준 미달**: 아래 평가에서 26개 기준 미달. 저장된 과거 외부 모델 출력에 대한 평가이므로 현재 앱 실시간 카페 정확도로 해석하지 않는다.
7. **검증 한계**: Windows 설치 파일은 생성했으나 Windows PC에서 설치·카메라 드라이버는 검증하지 못했다. 초로기 치매 관련 임상 예측 성능을 검증하는 데이터·모델은 없으며 소프트웨어 테스트로 이를 대신할 수 없다.

## 다음 결정

자동 판별을 더 진행하려면 보류 중인 행동/구간 모델 도입을 허용할지 결정하고, 개발자가 정답을 확인할 수 있는 카페 업무 5종·준비/이동·전화/응대·가림 포함 촬영 자료를 지정해야 한다. 이 개발용 정답 데이터와 실사용자에게 수동 분류를 요구하는 것은 별개다. 기존 데이터 및 보류 중인 외부 모델을 임의 삭제·교체하지 않았다.

## 재개 후 추가 수정 — 2026-11-10

- **3시점 전환의 가짜 움직임**: 대표 좌표를 프레임마다 고르지 않고 해당 기록에서 품질이 가장 나은 한 카메라로 유지한다. 미보정된 서로 다른 시점 좌표를 이어 붙여 물리적 움직임처럼 계산하지 않는다. 3대 동시 관측 조건과 3대 원본 보존은 유지한다.

## 핵심 성능 우선 재수정 — 업무 경계

앞선 수정만으로 실제 업무 경계를 해결하지 못했다는 사용자 지적에 따라, 카페/자체테스트의 구간 생성기를 교체했다.

- 개인화 표본을 구간 생성 **후** 분류하는 데만 쓰던 구조를 바꿔, 전체 동작 순서의 subsequence DTW로 연속 기록 안에서 시작·완료를 먼저 찾는다. 수동 확인 표본을 경계 참조로 우선 사용한다. 어깨 기준 정규화, 속도 차이 허용, 정적/부분 일치 거부, 추적 공백 통과 거부, 중복 억제와 다른 업무 후보 간 차이를 포함한다. 런타임에 사용자가 업무마다 시작·끝을 누르지 않는다.
- 개인 참조가 없거나 일치하지 않는 곳은 팔의 작업 진입·유지·복귀로 후보를 만든다. 속도/짧은 정지만으로 구간을 자르지 않고, 중간에 조용한 구간도 보존한다. 이것은 5종 업무 전체에 대해 검증된 범용 모델이 아니며, 팔 자세 기준은 아직 개발 기준이다.
- 시작/완료가 미관측이거나 내부 추적 공백이 큰 후보는 불완전 관측으로 보존한다. 자동 학습·완료 횟수·수행시간/최장 정지시간 이상 집계에서는 제외한다. CSV에 경계 방법·시작/종료 관측 여부·공백을 함께 내보낸다. 영상 맥락 모델이 스켈레톤 경계를 다시 넓히지 않도록 했다.
