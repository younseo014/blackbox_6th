# UTKinect 1차 스켈레톤 학습 결과

- 데이터: UTKinect-Action3D, 유효 클립 198개
- 분할: 홀수 피험자 5명 학습 / 짝수 피험자 5명 평가 (사람 중복 없음)
- 입력: 앱과 동일한 12개 전신 관절, 28프레임 정규화, 좌우 반전 허용 DTW
- 클래스: 9개 업무 원시동작
- 저장 모델: 학습 피험자의 유효 표본 전체 사용

## 성능

| 설정 | 정확도 | 신뢰도 기준 통과율 |
|---|---:|---:|
| 1-shot 기준선 | 30.6% (30/98) | 42.9% |
| 5-shot 중간 확인 | 59.2% (58/98) | 48.0% |
| 전체 표본 1차 모델 | 70.4% (69/98) | 58.2% |

정확도 변화: **30.6% → 70.4% (39.8%p)**

전체 표본 모델의 혼동행렬은 모델 JSON의 `evaluation`에 저장했다.

## 해석 제한

이 수치는 UTKinect 내부의 피험자 독립 평가다. 카페 현장의 원거리 RGB 카메라, 가림, 물체 상호작용에 대한 실성능을 뜻하지 않는다. 외부 3D 스켈레톤을 앱의 2D 공통 관절로 투영했으므로, 로컬 카메라 검증셋으로 재보정해야 한다. 특히 CARRY와 LIFT는 현장 적용 전에 추가 데이터가 필요하다.
